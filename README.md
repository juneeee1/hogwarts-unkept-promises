# 未赴之约 · 霍格沃茨

一个可以直接在浏览器中游玩的单机 3D 叙事探索游戏。

玩家会收到一封来自霍格沃茨的邀请，在分院后进入战后的城堡，探索礼堂、图书馆、魔药教室、天文台和移动楼梯等场景，并通过解谜和选择推进一条原创的平行故事。

本项目是非官方同人创作，与原著作者、出版社、影视公司及游戏发行方没有关联。

## 主要内容

- 完整的单人故事章节和 7 个谜题
- 分院结果会影响部分探索过程
- 简体中文、繁體中文、English、日本語、한국어五种语言
- 可移动探索的 3D 城堡、移动楼梯和场景互动
- 自动存档、存档导入与导出
- 桌面端和移动端横竖屏适配
- 所有剧情和规则都在本地运行，不需要登录、后端服务或 AI 生成

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## 构建和测试

```bash
# 构建 Storvia 静态版本
npm run build:storvia

# 预览静态版本
npm run preview:storvia

# 运行测试
npm test
npx tsc --noEmit
```

静态文件会生成到 `dist-storvia` 目录。

## 技术栈

项目使用 React、TypeScript、Three.js 和 Vite 开发。城堡、角色、分院帽、魔法效果与大部分场景物件由程序建模和原创贴图组成。
