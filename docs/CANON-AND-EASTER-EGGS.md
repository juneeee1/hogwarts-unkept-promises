# 原著依据与彩蛋清单

2026-09-07。用于第三版玩法讨论稿的编写依据。已核对下列官方资料；具体任务、关卡布置、战后续写和“如果”结局均为本项目同人设计，singleplayer-v1 已实现分院、斯内普平行首章，以及巧克力蛙、糖纸、沼泽、画像、R.A.B. 五处互动；表中的其他内容保留为后续设计依据。以小说叙事为主，电影建筑造型仅作为视觉参考。社交讨论的样本与解读见 [调研记录](./SOCIAL-RESEARCH-20260907.md)，它们不能替代原著事实。

## 叙事验收

- 每个重点细节都要有“看见/听见—操作—反馈”，而不只是贴一句名言。
- 主要物品要交代由谁保存、为何在此处、交还或使用后的结果；珍贵物件不能无缘无故满城散落。
- 彩蛋结果保存在本局进度里，并至少有一次后续场景回收；可通关后回补。
- 原著事实、电影视觉、原创续写、平行章节在开发文档中明确标记；游戏只在需要判断故事性质时作简短说明。
- 主线继续原著的人物关系与魔法边界；平行章节可以改变命运，但要写出行动与后果，避免一句咒语解决所有牺牲。
- 角色章节在相关线索出现后即可进入；平行故事与原时间线分别记录进度，不把不同历史的人物状态无解释地混用。
- 社交高赞评论用于理解感受；CP 偏好、演员纪念、电影差异与未核实的同人说法不能直接变成原著设定。
- 不自动播放付费 AI 对话；结局、彩蛋和角色基础互动都由预写内容与动画完成。
