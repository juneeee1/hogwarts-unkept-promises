# 霍格沃茨：未赴之约（第二版讨论稿）

2026-09-07。依据用户关于原著呼应、彩蛋与意难平的反馈重写。此文是待讨论方案：当前游戏仅实装视觉和移动交互，尚未加入分院判断、以下任务或结局。本轮代码修复的是分院帽红布穿插。

## 故事方向

设定为大战后的一个开学夜，玩家是参与城堡修缮的新生。校方准备一场重新欢迎学生、教职工和朋友的晚宴，但几封邀请与若干承诺还没有抵达该去的地方。玩家在分院之后，沿着城堡里熟悉的物件与人物痕迹完成这些未赴之约。

目标从“收集星图换寄语”改为“完成几件有具体对象、具体结果的事情，让晚宴真正发生”。建议主线 30–45 分钟；每条支线在场景里留下持续变化。暖意、幽默、探索与遗憾都有位置，不把每一处彩蛋都写成悲伤告别。

以七部小说为叙事依据，建筑视觉可以延续电影给玩家的熟悉感。新增剧情明确属于同人续写。原著中未发生的团圆属于另行标注的平行世界章节，不解释成“原著隐藏真相”。

## 场景：原著细节要能参与玩法

| 场景 | 可玩的设计 | 对应的叙事作用 |
| --- | --- | --- |
| 石桥 | 猫头鹰落在桥灯上，玩家替它找到掉落的邀请。巧克力蛙会从盒里跳走，追上后发现卡片上的人物暂时串门去了 | 先体验魔法世界的小幽默；邀请引出主线。邀请事件、蛙的路线为原创 |
| 礼堂 | 分院帽以情境对话了解玩家，也接受玩家表达的选择。席位与旗帜回应学院；发现一张原本没有姓名的宴会座位牌 | 身份是探索起点；玩家后续帮助的人会真实出现在结尾的座位与活动中 |
| 庭院 | 修复被破坏的草药架；在旧课本里发现一张被认真压平的糖纸，可选择妥善保留并归还纳威 | 原著中纳威珍惜母亲给的糖纸。续写重点是尊重它的意义，归还后花坛与感谢便笺发生变化，不写“一剂药治好父母” |
| 图书馆 | 读懂旧书的批注，重排被皮皮鬼打乱的索引，找到双面镜与旧信件的来历；帮助小精灵整理一份有署名的劳动记录 | 理解物件的用途和人的处境；读过的事实会让后续选择不同。镜子和信件为借展/档案，不把哈利的私人物品随便遗落在书架 |
| 魔药教室 | 致敬第一部的魔药逻辑关：用一组全新编写的线索辨别瓶子，调制修复旧墨迹的溶液；批注采用有性格的简短原创笔迹 | 正确操作显出被遮盖的署名或配方；逻辑、耐心与求证均可过关。药水不能复活、治愈所有创伤或改写记忆 |
| 楼梯与画像 | 卡多根爵士跨画框带路却偶尔走错；皮皮鬼挪动指路牌。墙角留一小块被保护起来的沼泽，完成观察互动可发现双胞胎焰火的线索 | 保留弗立维欣赏好魔法的幽默；把移动楼梯、画像串门和恶作剧变成路线谜题。具体任务是原创 |
| 天文台 | 用望远镜和观测记录解读夜间信号，完成前文约好的焰火联动；准备结束后从塔顶看城堡逐段亮灯，回礼堂参加晚宴 | 天文台是高潮的启动点；最终奖励回到真实可走、可互动的礼堂，而非弹出一页文字 |

原著细节的出处与版本区别见《原著依据与彩蛋清单》。谜题无需背诵冷门知识，所需线索都能在游戏里找到；熟悉原著的玩家会更早会意，但不熟悉者也能完成。

## 彩蛋分三种回报

1. **即时惊喜**：巧克力蛙逃跑、画像离开画框后从另一幅探头、皮皮鬼在玩家转身后换了路牌。每种都能引发短动作或一句原创对白，冷却后才再次触发。
2. **原著读者的会心一笑**：被保留的沼泽、两只不配对的袜子、认真压平的糖纸。先让玩家观察，再给可选的手记解释；正常探索不会强制长篇科普。
3. **结尾回收**：帮助画像找回位置，晚宴时它会跨画框赶来；完成双胞胎焰火支线，天花板下多出成对追逐的烟花；推动小精灵署名和来宾席位，晚宴中就有对应来宾与座位。放着不管则没有对应布置，避免“做没做都一样”。

隐藏支线可在通关后回补；不要求一次找全，也不把情绪高潮锁在付费或全收集后面。

## 结尾必须是场景与行动

### 主线结局：赴约

玩家回到礼堂，可以继续移动。修复过的旗帜展开，帮助过的画像过来串门，桌上的邀请变成姓名牌。未完成的支线保留未展开的邀请，通关后仍可继续。

第一条建议完整制作的角色支线是乔治与弗雷德：玩家从城堡留下的恶作剧痕迹中，找出一份尚未完成的双人焰火构想（同人原创）。图书馆负责理解笔记，魔药教室完成安全的配方谜题，天文台负责配合发射。结尾玩家和乔治分别点亮两个引信，成对的焰火飞过礼堂高窗；乔治得到的是有人愿意陪他把一件事情做完，不是一句“你已经走出悲伤”。

小精灵支线则把“受到平等尊重”变成看得见的结果：署名、对工作条件的自主选择、来宾席位。大战后的主线可以纪念多比，并让仍在生活的小精灵受益。多比本人出席属于下面的平行章节。

寄语只作为退场后可保存的一小页纪念，不承担当作结局的任务。

### 隐藏可玩章节：如果这一次

建议提供明确标注的平行世界短章，填补想要真正改变命运的愿望。它从具体的原著岔路出发，包含一个可操作的小段落、不同的后续事件与一场能继续互动的团圆。章节从通关后的故事册进入；镜子、冥想盆或有求必应屋不被解释为原著中可任意改写历史的装置。

| 意难平 | 原著锚点 | 平行世界里可操作的改变与回报 |
| --- | --- | --- |
| 哈利与小天狼星 | 那份没有及时打开的双面镜礼物 | 推荐先做这一章：在关键误判发生前完成“找到礼物—拆开包装—核实消息”的操作。镜面第一次得到回应，随后走入我们重写的事件链。最后哈利在格里莫广场与小天狼星完成一顿普通晚饭，玩家可摆盘、翻照片、选择聊天话题。不能简化成“一次通话保证所有人获救” |
| 弗雷德与乔治 | 双胞胎、恶作剧、共同创造魔法的默契 | 独立平行章保住弗雷德后，玩家和两人测试一件新玩笑产品，看他们把对方的话接完；结尾让两个人一起点燃烟花。改变战斗结果需单独写出可信的救援过程，不能用主线配方瞬间复活 |
| 卢平、唐克斯与泰迪 | 刚建立的家庭、父母未能陪伴孩子长大 | 平行章完成一段撤离和保护任务，结尾是两人陪泰迪准备上学行李。用具体生活动作回应遗憾；主线只采用战后的照料与传承，不声称他们幸存是原著事实 |
| 多比 | 自由、袜子、被当作朋友 | 平行章另写马尔福庄园脱险分支。团圆段落中，多比自己挑两只不同的袜子，再选择坐哪里、想做什么。他以客人和朋友的身份落座，不能变成解锁后继续无偿服务玩家的奖励 NPC |

第一版不同时制作四个完整救援章节。推荐先把“小天狼星的双面镜”做成一个 8–12 分钟样章，验证这种补遗憾的方式是否符合期待，再扩展其他人物。主线的乔治焰火任务可先作为短支线；若更想先看到双胞胎团圆，也可以调换首章优先级。

## 分院怎样服务主题

保留四学院选择与不同线索入口，但不把所有人格和人物命运按学院划死。同一玩家可以先勇敢行动、再认真求证、再帮助别人，也可以通过谈判找到办法。收尾需要整合不同学院的知识和帮助，呼应选择、友谊与共同守护学校。

- 格兰芬多入口：先行动，负责跨过移动阶梯把求助送到。
- 拉文克劳入口：先求证，从书页和镜子的用途找出被误读的信息。
- 赫奇帕奇入口：先照顾被忽略的人，从小精灵与画像处得到信任。
- 斯莱特林入口：先谈条件与规划路线，让原本互不合作的人愿意交出线索。

所有学院都能解锁每条角色支线，通关后可补齐其他探索。结尾差异记录玩家真正做过的事，不能只根据分院结果自动判定勇敢、善良或野心。

## 单机与 Storvia 的支持边界

主线解谜、分院判断、对话选项、互动动画、环境反馈和纪念页均可通过本地代码与预写内容完成，不需要 AI 生成。资源加载完成后，可独立运行；若要承诺关页后断网重开，则需要额外做离线缓存，当前版本没有此能力。

Storvia 官方 `save.get()/save.set()` 支持任意 JSON 存档，按游戏会话隔离，整个存档上限 256KB，并且不注入 AI。建议保存学院、任务阶段、谜题状态、收集品、已读对白、版本号；位置按检查点保存，避免逐帧写入。普通浏览器版使用本地存档；平台版初始化成功后使用平台存档。同步失败要保留本地待写状态、提示未同步，不能把空存档当成已通关数据覆盖。`save.set()` 是整体覆写，写入需要排队合并。

来源：[Storvia 属性与游戏存档](https://docs.storvia.ai/docs/creation/world-mode/state)。Storvia 预览模式的状态不持久保存，云存档验收需要发布后的实际会话，不能只凭本地预览下结论。来源：[快速开始](https://docs.storvia.ai/docs/creation/world-mode/getting-started)。

## AI 只做玩家主动选择的附加体验

如果希望增加陪伴感，建议第二阶段只开放「与画像自由交谈」或「向分院帽自由提问」。主线答案、道具获取与分院结果仍由明确的游戏规则维护。AI 可以用当前学院和已完成任务组织回应，不能修改付费状态、凭空发道具或改变已确认的学院。

玩家流程：点击指定 NPC → 先显示免费的预写对白及选项 → 玩家另点「自由交谈 · 将消耗花园币」 → 输入并主动发送 → 只发起这一条生成。进入场景、靠近 NPC、分院、施法、读线索、存档、恢复页面都不触发新的付费生成。若平台能提供可靠的本次价格，发送前展示；在未核实计价接口前，不编造具体币数或承诺固定费用。

必须落实的计费行为：

- 发送后立即锁定该请求的入口，跨组件共享在途状态，避免快速连点重复提交；一条指令不扇出给多个 NPC。
- 断线先恢复已有生成或读取已完成消息，不自动再次调用 send/generate/retry。恢复失败保持待核对状态，由玩家主动决定是否重新生成。
- 「重新生成」必须由玩家再点击，清楚说明会再次消耗花园币；返回页面不得自动执行。
- 停止生成不是撤销账单，官方说明已经产生的内容仍计费，界面文案不能说“取消后不扣费”。
- 官方文档未说明通用请求幂等键或固定价格查询 API。客户端锁定只能防误触，不能单独保证支付恰好一次。接入前需对平台实际 SDK/账单核实异常、刷新、多端与重连行为；无法确认时，先不上付费 AI。

这些约束来自平台当前接口：`send/generate/retry` 均扣费；`resume` 不发起 AI、不扣费；同一 topic 的在途生成有并发互斥。互斥不等于跨时间重复请求去重。来源：[Storvia 聊天 API](https://docs.storvia.ai/docs/creation/world-mode/chat)。

## 下一步建议与待决定事项

先制作“分院—画像/沼泽小惊喜—双面镜线索—可操作的平行结尾”样段，确认原著细节、自由探索与情绪回报能连起来，再扩展七个场景的完整主线。新增角色需要可近看的模型、表情与动作，工作量高于原先的文字寄语；不能把站桩人物加几句对白当作完成团圆。

需要优先决定的是第一条最想弥补的遗憾：小天狼星与哈利、弗雷德与乔治、卢平一家，还是多比。推荐双面镜，因为关键物件与“及时求证”的行动之间有直接联系，适合当前的探索和物件交互。
