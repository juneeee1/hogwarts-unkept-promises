## 美术与交互

人物重建为更圆的头型和脸颊，细小的鼻子、眼睛、眉毛、嘴巴和淡淡的腮红共同组成表情。脸部插画贴合连续的头部表面，取代浮在脸上的球状眼睛和独立眉毛。头发使用平滑的发帽和有厚度、逐渐收尖的分层发束；保留短身比例、衣领、纽扣、外袍和手中笔记。轻微转头和偏头保留，本版没有眨眼动画或表情捕捉。

信封和信纸现在处于同一个场景容器：拆蜡封、掀封口、抽纸、摊开阅读连贯完成。最终信纸使用生成的牛皮纸纹理，文字保持 HTML 排版，可以切换语言和滚动。修复了拆封前纸张从信封下方露出、横屏两侧露纸的问题。途中关闭会取消延时任务，重开后仍可正常拆信；只有按下阅读后的继续按钮才推进。回看已完成的信件只关闭面板，不再次推进。

学院、药材、星象和救援物品共用一套插画图集。24 个图案分别按实际边界裁切，再填充到有留白的方格中，避免相邻图案串入。修复了星盘嵌套 span 的双重位移、图标参与文字伸缩，以及生产打包时图片地址被错误拼接的问题。最后一项通过明确的图片 URL 导入修复，并用真实浏览器读取图片尺寸验证。

## 文案

原有 221 组条目逐项审读，42 组同步改写简中、繁中、英语、日语和韩语。另增加“本章已完成”标签，最终共 222 组。谜题答案仍使用稳定 ID，文字改写不改变解题规则或存档结构。

叙述使用平实的原创语言，保留人物的口气与世界细节。邀请函改成有具体委托和落款的信；批注、借阅登记、担架上的袖口、留出的茶杯和乔治的便笺承担故事推进。移除了许多替读者总结情绪的句子，也减少了插在剧情中的设定解释。平行救援仍有明确标识，不把新增的幸存故事说成原著情节。

例如，“他不必永远只为过去活着”改成了归档时的一句吩咐：“第二层。别把索引夹在最底下。”收好记录后，桌上才有地方放新配方和幼苗。结尾保留焰火、便笺和身边的座位，让玩家通过这些小事感受变化。
